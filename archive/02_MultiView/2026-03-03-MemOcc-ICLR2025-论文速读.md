## 1. 🔪 今日锐评
**物理痛点：长时序遮挡下的物体“记忆蒸发”与瞬时盲区风险**。
当前的 BEV 时序融合方案通常只维持一个极短的时间窗口（约 1-2 秒）。这种“金鱼般的记忆”在面对真实世界的拥堵场景时显得力不从心。当自车在繁忙路口等待长红灯，侧面一辆大货车完全遮挡摄像头 10 秒以上时，BEV 特征池中的历史信息会逐渐衰减至零。这意味着货车后面原本存在的行人会从模型的“内存”中被抹除。MemOcc 通过建立基于 Key-Value 检索的 “永久记忆银行 (Memory Bank)”，解决了感知系统的“遗忘”物理痛点。它让自动驾驶感知不仅具备了对当前的观察力，更具备了对历史环境的“持久脑补”能力，解决了由于时间窗口过短导致的感知幻觉问题。

## 2. 🏗️ 模型架构 (Architecture Map)
- **Local Feature Extractor**: 提取当前时刻 BEV 特征 [B, 256, 128, 128]。
- **Memory Bank (LMB)**: 跨度达 1 分钟的时空 Token 存储池 [B, 1024, 256]。
- **Memory Recall Module**: 基于 Cross-Attention 的特征找回逻辑。
- **Tensor Shape 流**:
    - `Current BEV`: [B, 256, 128, 128]
    - `Memory Bank`: [B, 1024, 256]
    - `Recalled Feat`: [B, 256, 128, 128]

## 3. 💡 核心创新 (Math & Pseudo-code)
**特征准入与动态淘汰策略**:
```python
# PyTorch 风格伪代码
def update_memory_bank(self, current_feat, memory_pool):
    # 1. Compute Confidence Mask
    conf_mask = self.confidence_head(current_feat) 
    # 2. Filtering High-Value Tokens
    high_val_tokens = current_feat[conf_mask > 0.85] 
    # 3. Dynamic Pruning (LRU Policy)
    updated_pool = self.lru_pruning(memory_pool, high_val_tokens)
    return updated_pool
```

## 4. 📉 Loss 函数详解

- **L_temporal**: 帧间一致性损失，平滑特征切换。
